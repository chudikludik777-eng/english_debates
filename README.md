# Oxus Debate League

Одностраничный сайт международного онлайн-турнира по дебатам на английском для школьников Центральной Азии.

## Открыть сайт

Для полной работы с заявками запустите в папке проекта:

```powershell
npm start
```

Затем откройте `http://localhost:4173`. Сборка и установка пакетов не нужны.

## Подключить ваши ссылки

В `app.js` замените:

- `botUsername: "YOUR_ODL_BOT"` на username бота из `@BotFather`, например `OxusDebateBot`;
- `instagramUrl` на настоящий адрес Instagram;
- `registrationEndpoint` уже указывает на встроенный сервер `/api/applications`.

Настройки уже лежат в вашем локальном `.env`. Не публикуйте токен бота в `app.js`, GitHub или Instagram.

## Как работает безопасная регистрация через Telegram

Сайт собирает заявку и передаёт её на ваш сервер. Сервер создаёт ID заявки и возвращает его в виде `{ "applicationId": "odl_123" }`. После этого сайт открывает ссылку:

`https://t.me/YourBot?start=odl_odl_123`

Пользователь жмёт **Start** в вашем боте. Telegram передаёт боту настоящий `telegram_user_id`, затем бот просит поделиться контактом через встроенную кнопку Telegram. Поэтому номер не вводится вручную на сайте и заявка привязана к реальному Telegram-аккаунту.

Всё это уже реализовано в `server.js`: бот обрабатывает параметр `start`, находит заявку по ID и присылает организаторам красиво отформатированное сообщение с именем, страной, возрастом, школой, командой, контактом и ссылкой на Telegram-профиль.

## Как это запускается сейчас

После `npm start` сайт и бот работают на вашем компьютере. Бот использует long polling, поэтому для работы не нужны домен, HTTPS или webhook. Просто держите окно с `npm start` открытым.

Бота нужно добавить в ваш организационный чат или канал, а его `TELEGRAM_ADMIN_CHAT_ID` уже указан в `.env`. Если бот не видит этот чат, Telegram вернёт `chat not found`: добавьте `@chort11111bot` в чат и, если это канал, выдайте ему право публиковать сообщения.

Если ID неизвестен или был скопирован из другого чата, отправьте сообщение в нужную группу после добавления бота и временно запустите только один экземпляр приложения. В логах polling появится update, из которого можно взять `message.chat.id`; для супергруппы ID обычно начинается с `-100`. После замены `TELEGRAM_ADMIN_CHAT_ID` перезапустите сервер. При старте сервер сам проверит доступ к чату и повторит отправку ранее подтверждённых заявок с `organiserNotified: false`.

Для одного Telegram-бота должен работать только один процесс с polling. Иначе Telegram отвечает `Conflict: terminated by other getUpdates request`, и бот не получает обновления.

Для будущего хостинга на сервере можно отключить polling (`TELEGRAM_USE_POLLING=false`) и настроить webhook на `https://ваш-домен/telegram-webhook` с тем же `TELEGRAM_WEBHOOK_SECRET`.
